UNO Multiplayer Project အတွက် API Endpoints အပြည့်အစုံ ကို အောက်မှာ Module အလိုက် ခွဲပေးထားပါတယ်။

သုံးမယ့် Architecture ကတော့ -
- ASP.NET Core Web API
- Blazor
- SQL Server + EF Core
- SignalR
- JWT Authentication
- YARP API Gateway
- Game Modes: Classic, No Mercy, Custom, Team
- Players: 2–10

Play Card Example:
POST /api/games/1/actions/play-card


{
  "gameCardId": 25,
  "chosenColor": "Red"
}


Draw Card Example:
POST /api/games/1/actions/draw-card


{
  "drawCount": 1
}


drawCount ကို Client က အလိုရှိသလို သတ်မှတ်ခွင့်မပေးသင့်ပါဘူး။ Server က လက်ရှိ Rule နဲ့ Game State အရ ဆွဲရမယ့်အရေအတွက်ကို ဆုံးဖြတ်သင့်ပါတယ်။ အထက်ပါ Request က နမူနာအတွက်သာ ဖြစ်ပါတယ်။

13. SignalR Real-Time Endpoints
UNO Multiplayer ဖြစ်တဲ့အတွက် REST API တစ်ခုတည်းနဲ့ မလုံလောက်ပါဘူး။ Player တွေရဲ့ Game Actions တွေကို အချိန်နဲ့တစ်ပြေးညီ ပို့ဖို့ SignalR သုံးပါမယ်။
SignalR Hub
/api/hubs/game


Direction	Event	Description
Client → Server	JoinRoom	Join Room
Client → Server	LeaveRoom	Leave Room
Client → Server	SendChat	Send Message
Server → Client	PlayerJoined	Player Joined
Server → Client	PlayerLeft	Player Left
Server → Client	PlayerReadyChanged	Ready Status Changed
Server → Client	GameStarted	Game Started
Server → Client	GameStateUpdated	Game Updated
Server → Client	CardPlayed	Card Played
Server → Client	CardDrawn	Card Drawn
Server → Client	TurnChanged	Turn Changed
Server → Client	PlayerEliminated	Player Eliminated
Server → Client	GameFinished	Game Finished
Server → Client	ReceiveChat	New Chat Message

SignalR မှာ Client က Server ကို PlayCard လို Hub Method ခေါ်နိုင်ပေမဲ့ REST Endpoint နဲ့ တူညီတဲ့ Application Use Case ကို အသုံးပြုသင့်ပါတယ်။ Rule Validation ကို Hub ထဲမှာ သီးခြားထပ်မရေးပါနဲ့။
