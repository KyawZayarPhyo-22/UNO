###Project တစ်ခုချင်းစီရဲ့ တာဝန်

Project	တာဝန်
UnoGame.APP	Blazor UI, Pages, Components
UnoGame.Gateway	API Gateway, YARP Routing
UnoGame.API	Controllers, SignalR Hub, API Host
UnoGame.Domain	Game Entities, Game Modes, Rules
UnoGame.Application	Use Cases, Business Workflow
UnoGame.Infrastructure	EF Core, SQL Server, Identity, JWT
UnoGame.Shared	DTOs, API Contracts


###Game Mode တစ်ခုချင်းစီရဲ့ အလုပ်လုပ်ပုံ
ဥပမာ User က No Mercy ရွေးလိုက်ရင် -
1. Frontend က GameMode.NoMercy ကို API ဆီပို့မယ်။
2. API က Application Layer ကို ခေါ်မယ်။
3. Application က GameModeFactory ကို အသုံးပြုပြီး No Mercy Engine ကို ရွေးမယ်။
4. NoMercyGameEngine က No Mercy Rules နဲ့ Game State ကို စီမံမယ်။
5. SignalR က Player အားလုံးဆီ Game State Update ပို့မယ်။
6. Infrastructure က လိုအပ်တဲ့ Game Data တွေကို SQL Server မှာ သိမ်းမယ်။
အရေးကြီးတဲ့ Design အချက် ၃ ခု
- Classic နဲ့ No Mercy တို့ရဲ့ Card Rules, Actions, Validators ကို အချင်းချင်း မရောပါနဲ့။
- Player, Room, Authentication, Match History လို Common Features တွေကို ပြန်သုံးပါ။
- Game State ကို Server ကပဲ ထိန်းချုပ်ပါ။ Client က ပို့တဲ့ Card Move ကို Server က Validate လုပ်ပြီးမှ လက်ခံပါ။
